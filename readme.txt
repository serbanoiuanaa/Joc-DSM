ClinQuest — PWA pentru iPhone

1. Publicați CONȚINUTUL acestui folder pe o gazdă HTTPS (Netlify, GitHub Pages etc).
2. Deschideți adresa publică în Safari pe iPhone.
3. Safari -> Share -> Add to Home Screen / Adaugă la ecranul principal.
4. PWA se poate deschide separat și funcționează offline după prima vizită cu internet.

Nu poate fi instalată direct din arhivă pe iOS.
Progresul este salvat local pe dispozitiv și nu se sincronizează.
Conținut educațional introductiv, nu versiune integrală sau validată a DSM.
